🌟 smile PCL Mainpage - 小沐の整合包 小贴示
这是一个专为 PCL2 (Plain Craft Launcher 2) 制作的自定义主页卡片。采用了左文右图的清爽排版，并集成了快捷刷新、加群、内存优化等实用功能。

✨ 功能特性
🎨 左文右图布局：左侧展示欢迎语与下载提示，右侧配有纳西妲图片。

🔄 隐秘刷新主页：点击右侧的 红色版本号 (V26.11.08) 即可直接触发刷新主页（无需按 F5）。

💡 醒目提示：使用 MyHint 组件高亮显示“游戏下载功能已通过补丁修补”。

🔗 快捷按钮：底部提供“一键加群”与“一键内存优化”按钮，方便玩家快速操作。

🚀 如何安装
打开 PCL2 启动器。

点击顶部导航栏的 设置 -> 个性化 -> 主页。

在“主页预设”中选择 “自定义主页”。

点击 “打开主页文件”（或打开 PCL2 所在目录下的 PCL\Setup.ini 所在文件夹）。

将本项目的 .xaml 文件内容复制到对应的文件中并保存。

返回 PCL2 主页，即可看到效果（如果没有变化，请按 F5 刷新）。

⚠️ 注意：请确保你的 PCL2 版本在 2.10.9 及以上，否则“刷新主页”事件可能无法正常生效。


2. 修改链接与按钮事件
所有按钮的点击行为由 EventType 和 EventData 控制：

修改加群链接：找到 EventData="https://qm.qq.com/q/FrIY6Mps0q"，把网址换成你的 QQ 群链接即可。

刷新主页：EventType="刷新主页"。如果不想让点击刷新后弹窗提示，可以加上 EventData="任意字符"。

弹出窗口：EventType="弹出窗口"，并在 EventData 里写上 标题|内容，即可弹出一个提示框。

3. 调整排版与间距
在 XAML 中，控制距离的属性主要有两个：

Margin (外边距)：控制控件之间的距离。

Padding (内边距)：控制控件内部文字与边框的距离。

四个数字的顺序：永远是 左, 上, 右, 下。

例如：Margin="0,10,0,0" 代表距离上方 10 的距离。

小技巧：如果觉得两行文字离得太远，可以用负数，比如 Margin="0,-4,0,0"，强行把它们拉近。

4. 为什么版本号是一个“隐形按钮”？
因为 PCL2 自带的 MyButton 控件不支持直接调整 FontSize，且自带高亮框。为了保留原版红色加粗的字体，同时又不出现难看的灰色框框，代码使用了 Grid 叠加：

底层是一个普通的 TextBlock 显示文字。

顶层是一个 Opacity="0"（完全透明）且锁定了 Width="75" Height="20" 的 MyButton 负责接收点击。

如果要改版本号文字大小，请修改底层 TextBlock 的 FontSize，并适当调整顶层透明按钮的宽高即可。
