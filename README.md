# 🌟 smile PCL Mainpage - 小沐の整合包 小贴示

这是一个专为 **PCL2 (Plain Craft Launcher 2)** 制作的自定义主页卡片。采用了左文右图的清爽排版，并集成了快捷刷新、加群、内存优化等实用功能。

## ✨ 功能特性

- **🎨 左文右图布局**：左侧展示欢迎语与下载提示，右侧配有纳西妲图片。
- **🔄 隐秘刷新主页**：点击右侧的 **红色版本号 (`V26.11.08`)** 即可直接触发刷新主页（无需按 F5）。
- **💡 醒目提示**：使用 `MyHint` 组件高亮显示“游戏下载功能已通过补丁修补”。
- **🔗 快捷按钮**：底部提供“一键加群”与“一键内存优化”按钮，方便玩家快速操作。

---

## 🚀 如何安装

1. 打开 PCL2 启动器。
2. 点击顶部导航栏的 **设置** -> **个性化** -> **主页**。
3. 在“主页预设”中选择 **“自定义主页”**。
4. 点击 **“打开主页文件”**（或打开 PCL2 所在目录下的 `PCL\Setup.ini` 所在文件夹）。
5. 将本项目的 `.xaml` 文件内容复制到对应的文件中并保存。
6. 返回 PCL2 主页，即可看到效果（如果没有变化，请按 `F5` 刷新）。

> **⚠️ 注意**：请确保你的 PCL2 版本在 **2.10.9 及以上**，否则“刷新主页”事件可能无法正常生效。同时，请确保图片路径（`PCL/PCL/nahida.png`）存在。

## 🛠️ 如何自定义修改 (DIY 指南)

如果你想根据自己的服务器修改文字、链接或样式，请参考以下指南。

### 1. 字体大小、颜色与粗细怎么设置？
在 PCL2 的 XAML 中，文字样式主要依赖于 `<TextBlock>` 控件，你可以修改以下属性：

- **字体大小 (`FontSize`)**：控制文字大小，数字越大字越大。
  *例如*：`FontSize="14"`（默认正文大小），`FontSize="12"`（较小），`FontSize="16"`（较大）。
- **文字颜色 (`Foreground`)**：控制字体的颜色，使用十六进制颜色代码。
  *例如*：`Foreground="#1170D0"`（蓝色），`Foreground="#E74C3C"`（红色），`Foreground="#333333"`（深灰色）。
- **字体粗细 (`FontWeight`)**：控制文字是否加粗。
  *例如*：`FontWeight="Bold"`（加粗），如果不写或者写 `Normal` 则是常规粗细。
- **字体 (`FontFamily`)**：虽然较少用到，但你可以指定特定的字体。
  *例如*：`FontFamily="Microsoft YaHei"`（微软雅黑）。

**修改示例：**
```xml
<!-- 把欢迎语改大一点、变成绿色、不加粗 -->
<TextBlock TextWrapping="Wrap" FontSize="16" Foreground="#2ECC71" 
           Text="欢迎你来游玩小沐の整合包..." />
